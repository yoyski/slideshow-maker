   - Wait for generation

   - Click "Download video"
   - MP4 saves to your Downloads folder

================================================================================
                         TROUBLESHOOTING QUICK FIXES
================================================================================

PROBLEM: "Port 5000 already in use"
SOLUTION: Close other applications using port 5000

PROBLEM: Import errors / "No module named..."
SOLUTION: Run: pip install -r requirements.txt

PROBLEM: Microphone not working
SOLUTION: Grant browser microphone permission in browser settings

PROBLEM: FFmpeg not found
SOLUTION: Optional but recommended - install from https://ffmpeg.org

PROBLEM: Permission denied on run.sh (Mac/Linux)
SOLUTION: Run: chmod +x run.sh

Need more help? See INSTALLATION.md or README.md

================================================================================
                         AUDIO PROCESSING FEATURES
================================================================================

Noise Reduction:
  • 0% = No reduction (clean recordings)
  • 30-50% = Recommended (most cases)
  • 70-80% = Heavy reduction (noisy rooms)
  • 100% = Maximum (very noisy)

Podcast Polish (Optional):
  • High-pass filter (removes rumble)
  • Dynamic compression (evens dynamics)
  • EQ enhancement (adds clarity)
  • Loudness normalization
